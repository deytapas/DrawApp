# Collaborative Drawing App 🎨

A real-time collaborative drawing application that allows multiple users to draw, sketch, and collaborate on a shared canvas simultaneously. The application uses WebSocket communication to synchronize drawing actions instantly between connected users.

## 🚀 Features

- Real-time collaborative drawing
- Multiple users can draw on the same canvas simultaneously
- Instant synchronization using WebSockets
- Pencil, brush, eraser, and color selection tools
- Canvas clearing and drawing management
- User-friendly and responsive interface
- Secure user authentication
- Persistent storage for users and drawings
- Smooth real-time communication with low latency
